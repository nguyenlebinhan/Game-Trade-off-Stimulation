## Trạng thái

Repository dùng React + TypeScript + Vite. MVP hiện có game shell responsive, system model state tái sử dụng được, simulation engine deterministic và UI tích hợp cho workload, architecture actions, run/step/pause/reset, metrics trước/sau cùng explanations và assumptions.

## Lệnh phát triển

```bash
npm install
npm run dev
npm test
npm run build
```
