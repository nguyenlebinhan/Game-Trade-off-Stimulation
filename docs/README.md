## Trạng thái

Repository được khởi tạo cùng nền tảng React + TypeScript + Vite. MVP hiện tập trung vào khung màn chơi responsive cho campaign “Cứu shop trước giờ flash sale”; simulation engine chưa bắt đầu.

## Lệnh phát triển

```bash
npm install
npm run dev
npm test
npm run build
```
